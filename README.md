# ShortLink TTL Engine — сервис сокращения ссылок (Кейс PROMO IT)

Сервис для генерации и администрирования коротких ссылок на **Java 25 (LTS)**, разработанный по техническому заданию компании **PROMO IT**. Каждая ссылка привязывается к конкретному пользователю через UUID, имеет строгий лимит переходов и автоматически удаляется фоновым планировщиком на виртуальных потоках при истечении времени жизни (TTL).

## Архитектура и ключевые решения
Проект построен по принципам **Clean Architecture** без внешних фреймворков:
- **core** — доменная модель, бизнес-сценарии и порты ввода-вывода.
- **infra** — потокобезопасное хранилище на базе ConcurrentHashMap, генератор кодов SHA-256 + Base62, адаптер браузера и конфигурация на базе Java 25 Record (JEP 513).
- **ui** — интерактивный CLI-контроллер на базе Pattern Matching и фоновый демон очистки просроченных ссылок на виртуальных потоках.
